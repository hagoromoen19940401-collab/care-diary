# 業務日誌

勤務表から、その日の勤務区分別に職員を自動転記する介護日誌です。公開版には職員名や勤務データを内蔵せず、初期状態は空です。読み込んだデータはブラウザ内に保存され、自動転記される職員名は苗字だけで表示します。

## 使い方

1. `index.html` をブラウザで開きます。
2. 管理者は「設定」で管理者パスワードを入力し、「勤務表を読み込む」から、さくら・けやき・看護師を含む `.xlsx` を選びます。読取結果を確認・修正し、「確定して保存」を押すと反映されます。従来の介護士用Excel、CSV、TSV、JSONも引き続き読み込めます。
3. 日付を選ぶと、読み込み済みの勤務表から職員名が自動転記されます。
4. 日誌本文や職員欄は必要に応じて手修正できます。
5. 「JSONバックアップ」で勤務表と日誌内容を保存できます。

## 入浴予定表

管理モードの「入浴予定表を読み込む」から `.xlsx` を選ぶと、「入浴予定データ」シートの曜日、AM / PM、入浴区分、所属、氏名をブラウザ内へ保存します。この一覧シートがない従来形式では、月曜日原本から土曜日原本までの各シートにあるAM・PM、一般浴・特浴、所属、氏名の位置関係を読み取り、同じ内部形式へ変換します。日誌の日付に対応する曜日から、さくら・けやき別の一般浴・特浴人数を合計して未編集の欄へ自動表示します。日誌側で手入力した値は自動値より優先され、入浴予定表を更新しても削除されません。

「入浴予定を確認」は一般職員も利用でき、曜日別の氏名、所属、AM / PM、入浴区分を確認できます。SSは明細を別に保持し、通常人数には含めません。機械浴・ストレッチャー浴など対応が確定していない区分も自動集計せず、従来どおり日誌へ手入力します。保存した入浴予定はJSONバックアップ・復元の対象です。

## 管理者用の簡易ロック

「設定」を開いたときは、パスワード入力欄1つと「管理設定を開く」ボタンだけを表示します。保存済みの管理者パスワードがない初回は、ここへ入力した8文字以上の文字列を初期パスワードとして保存します。管理画面の「パスワード変更」は別画面で開き、新しいパスワードと確認用パスワードが一致した場合だけ変更します。パスワードの平文はHTMLやブラウザ保存領域へ保存せず、ランダムなソルトとPBKDF2-SHA-256で作ったハッシュだけをこの端末のブラウザに保存します。ブラウザを再読み込みすると一般モードへ戻り、管理モード中も約15分操作がなければ自動的に終了します。

この仕組みは、勤務表の読み込みやデータ復元を一般画面から誤って実行しないための簡易ロックです。単体HTML上のJavaScriptは利用者が解析・変更できるため、本人確認や不正アクセス防止を保証する本格的な認証ではありません。正式運用ではSupabase Authなどの認証と、データベース側のRLS（行レベルセキュリティ）を組み合わせてください。認証導入時は、認証済みプロフィールの役割を`setCurrentUserRole()`へ渡す構造です。

パスワードを忘れた場合、ブラウザの当サイト用保存データを消すと再設定できますが、日誌や勤務表の保存データも失われる可能性があります。事前にJSONバックアップを安全な場所へ保管してください。

## 看護師勤務表

統合Excelでは勤務表シートから、年月、日付列、さくら・けやき・看護師の見出し、職員行、☆用行、予定行を検索します。候補シートが複数ある場合は選択画面を表示します。人数・行番号・日付列番号は固定していません。職員名はフルネームで保存し、日誌では苗字を表示します。同姓の職員は番号を添えて区別し、確認画面に警告を出します。☆が0個または複数の日も警告します。看護師の氏名行は空欄を通常出勤、「休」「有」を休みと判定し、「会議」やその他の記号は要確認にします。この空欄ルールは介護士や☆用行には適用しません。

番号のない氏名行は勤務記号が並ぶ場合だけ職員候補に入れ、警告します。番号も勤務記号もない行は自動確定せず、必要なら確認画面の「職員行を追加」から登録してください。受診と会議などが同じ予定セルに混在する場合は全文を共通予定として保持し、分け方を警告します。

既存の同月データを読み直すと、前の勤務表と看護師データは履歴に保持され、JSONバックアップに含まれます。日誌への手入力は別に保存されます。読み込みや確定前の失敗では、現在の正常データを置き換えません。

「看護師勤務表を読み込む」からJPEG・PNGなどの画像、または `.xlsx` を選べます。画像はTesseract.jsを使ってブラウザ内でOCRし、横書きと縦書きの日本語を読み取ります。画像自体は外部へ送信しません。初回はOCRプログラムと日本語学習データをCDNから取得するため、インターネット接続が必要です。

OCR結果は日付別の確認画面に表示されます。氏名、夜間オンコール、受診予定、その他の予定を修正し、「確定して保存」を押したデータだけが日誌へ反映されます。写真の表構造、勤務記号、☆は誤認識しやすいため、必ず元の勤務表と照合してください。勤務記号の意味は自動推測しません。

現在の写真サンプルではOCR処理と対象年月の認識までは確認できましたが、細い日付セル、☆、縦書き予定の日付別割当は十分な精度で認識できていません。写真OCRでは氏名行と勤務記号を確実に対応付けられないため、該当項目は「要確認」のまま表示し、確認画面で手動入力します。

看護師だけの別形式Excelは配置が未登録のため、自動解析できない場合に手動確認表を開きます。

確定データは対象年月ごとにブラウザへ保存され、「看護師データを確認・修正」から編集できます。月別看護師データとOCR原文もJSONバックアップ・復元の対象です。

公開版のHTMLには職員情報や勤務データを内蔵していません。読み込んだ勤務表、日誌、入浴予定、看護師データはブラウザ内に保存されます。生成したJSONバックアップには個人情報が含まれるため、外部へ共有せず安全に保管してください。
